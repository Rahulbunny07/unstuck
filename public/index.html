What it does

Example: one engineer finds that a service fails because an older SQLite build has no JSON functions. They record the error text, the versions affected, the confirmed cause, the fix and how it was checked. When a teammate hits the same error, Unstuck shows that record first, with the environment it was recorded for, and uses no AI. Similar error text is not proof of the same cause, so you are always told to check the environment matches.

Works today

  • Team workspace: members add records, the owner approves them, and approved records are matched first.
  • Shared library of 16 curated fixes, matched before any AI call.
  • AI fallback for new errors, labelled "not verified" until someone confirms it.
  • Evidence quotes checked against your pasted text; secrets removed before analysis.
  • Retry that remembers failed fixes, daily limits, and honest labels on every answer.
  • Config files, a live site check, and credits you can buy for extra AI answers.

Company knowledge search and AI debugging help already exist as products. Unstuck's bet is narrower: validated records with their environment, checked before AI is used.

How it works

  1. Cleans your log. Removes secrets and keeps only the lines that matter, so less is sent and nothing sensitive leaves.
  2. Checks known fixes first. If the error was solved before, you get that answer instantly with no AI call.
  3. Asks the AI only when needed. New errors get a cheap model first and a stronger one only if the first fix fails.
  4. Learns from you. Your Worked or Didn't work tap decides which fixes rise in the library.
